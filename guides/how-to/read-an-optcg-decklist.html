How to read an OPTCG decklist

A line like 4xOP17-039 means four copies of set OP17 number 039. Leader IDs look the same (OP17-079, OP13-004). Match the leader ID before you copy the rest of the 50 cards.

FAQ

OPTCG

Why does the leader ID matter?

Several characters have more than one leader. OP17 Luffy is not RG Luffy. OP16 Ace is not OP13 Ace.

Why 50 cards?

Constructed format. Consensus lists on a hub are averaged, then filled back to 50.
